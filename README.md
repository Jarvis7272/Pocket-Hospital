
# Pocket Hospital

Pocket Hospital is a user-friendly application designed to help users find common medicines, best doctors, and hospitals in their vicinity. The app aims to enhance healthcare accessibility by providing efficient search options for essential healthcare needs.




## Features:
- Medicine Finder: Users can search for common medicines based on their symptoms and get information on dosage and frequency.
- Doctors Directory: A curated list of the best doctors nearby, categorized by specialization.
- Hospital Finder: Information on nearby hospitals for quick and easy access to healthcare facilities.

## Prerequisites:
- Java Development Kit (JDK)
- Apache NetBeans
- MySQL or any relational database

## Technologies Used:
- Java: Core development language for the application.
- SQL: Database management to store information about medicines, doctors, and hospitals.
- Apache NetBeans: IDE used for the development of the application.
- Photoshop: Used to design the UI components and icons.
